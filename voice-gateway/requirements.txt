# l'import avec "ImportError: pyarrow requires NumPy 2.0 or newer". Pinner
# ici garantit aussi un nouveau hash de ce fichier, qui invalide le cache
# Docker de la couche `pip install -r requirements.txt` si elle avait figé
# une résolution numpy antérieure.
